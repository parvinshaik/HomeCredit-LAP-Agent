# Home Credit – LAP Voice Agent

## Overview
AI voice agent built using **Retell AI** for Home Credit's Loan Against Property (LAP) pre-qualification process.

## Features
- Verifies the customer and explains the LAP offer up to ₹75 Lakhs.
- Collects the required eligibility details.
- Handles information provided out of order.
- Identifies ineligible customers and ends the call politely.
- Routes existing loan/EMI reduction requests to a Loan Transfer Specialist.
- Transfers qualified customers to a Senior Loan Expert.

## Eligibility Criteria
- Property: Residential, Commercial, or Industrial
- Ownership: Sole or Joint
- Original property documents: Required
- Loan amount: Up to ₹75 Lakhs
- Occupation: Salaried/Self-Employed with bank-based income
- Tenure: 3–15 years

## Platform
**Retell AI – Conversational Flow Agent**

## Testing
Test scenarios include:
- Eligible customer
- Agricultural property
- Cash income
- Documents unavailable
- Loan amount above ₹75 Lakhs
- Invalid tenure
- Existing property loan
- EMI reduction request
- Out-of-order responses
